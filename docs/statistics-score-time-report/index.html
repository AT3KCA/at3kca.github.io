documents/statistics-score-time-report

学了这么多数物化生知识，我觉得也不能光学了，用来解决实际问题也挺不错的。所以这次作为一个知识利用的测试，来实践一下怎么把课上学的东西和实际联系起来。

在这篇文档之前我从未做过任何正经的分析，也许有地方需要改正吧。

来源

做了一个致力于测试你的二次元角色喜好的问卷，对结果的不准确加以思考。

总体想法

有时候我们会做一些问卷，然后有程序会根据我们的输入得到最终结果。不过，很多都聚集在问卷的具体内容上，我认为这种测试形式忽略了个体的一部分主观能动性，即在这个问卷上停留的时间。

大致认为，个体喜欢一个事物的程度，可以称之为评分和他在这个问题上停留的时间有关系。个体越喜欢，就会花更多的时间去观摩、思考这个事物，随之而来的，停留的时间越长。特例也是存在的，如果样本特别喜欢一个事物，那他很有可能不假思索的直接选择最高分，使得停留时间反而减少了。

所以我推断，停留时间和评分呈正相关，当评分高到一定程度后，时间会有所回落

建立模型

数据

根据评分和时间的关系，我们可以想到，不同的时间可能对应一个评分，如果以评分为自变量，就会导致结果曲线变得不好分析，并且，这种规定方式不符合现实思维，给出评分的时间代表了个体对这一事物的喜好程度，所以说，是评分决定了时间，而不是时间决定了评分。评分是个体给出的，与时间无关。

我们建立模型，令评分为P，停留时间为t，以P为横轴，t为纵轴，建立P-t图像，对数据进行分析。

对于数据结果，因为每个人的反应时间是不同的，做出评分的时间也会有所不同，所以我们先对得到的样本进行标准化，用样本的单个数据和样本的基准数据的比作为停留时间的指示量，这样既减轻了个体差异，标准化的数据也为分析带来了便利。

不过，如何得到每个样本的基准数据也是需要思考的。

问卷

问卷的设计不宜复杂，由三个部分组成，用最少的元素参与得到较为现实的时间和评分数据，防止无关变量干扰。这简直就是我答的生物大题啊

角色名和简短的介绍，角色图片以及评分选项

数据来源

通过编写带有计时功能的特别问卷程序，以ASA/HOOK/SMEE玩家群的玩家为目标，建立HOOK系游戏角色评分问卷，对玩家样本数据进行收集。

说白了，就是我临时搭个答题服务器然后把地址分享给群友呗，得到足够的数据就可以关闭了。
