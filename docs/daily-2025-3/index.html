2025/3/9

我的天,这几个星期都特别累,这周也是

终于抽出一点时间更新一下这个内容

最近没干什么

没学什么

感觉日复一日的

没有留下一些印象就过去了

这里是北京丰台,其实和东西海朝差远了

就是北京的郊区

我就直说了罢,我在北京十中上学,别看带着个北京头衔,其实就是个丰台的普通高中

中考我是601考进了晓月苑分校

这样看来,能进十中真是奇怪的,而且就我们这一届会留在十中本部上学

是吧,没有北京中心城区的好资源,没有外地山河四省的好脑子

但就能以比较低的成绩考上一个普通大学

这无疑是对外地考生的不公平

挂着个北京ip,当然錒,这里不是说北京十中的同学们学习不好,这里还是有比较聪慧的同学

其实,普通人的生活都没什么不一样的

为什么因为ip的差异来互相攻击呢

我的手机卡回来了,因为学校有时要用手机做听说
