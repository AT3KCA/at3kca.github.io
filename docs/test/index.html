说欺骗

总能听到诸如“别骗人了”、“还在骗自己”之类有关 “欺骗” 的言论，不由得引发我思考：欺骗到底是在骗什么呢？

撒谎，其实就是种欺骗行为，我们让别人相信我们干成了什么，但实际上什么也没干。欺骗别人后，他们会认为我们的确是干了些什么，不过，真相只有我们自己知道，我们的确是什么也没干了。这个过程中，表面上，我们通过撒谎欺骗蒙混过关，让别人对我们的作为蒙上了一层虚假的滤镜。我认为，更深层，就是在骗自己了，我们其实是给欺骗别人的自己盖上了一层不愿捅破的破布。

欺骗别人，首先要让自己相信这个事实是真的，比如“我写作业了，不过忘在了家里”，明眼一看上去就是假的，为什么我们敢说出来，原因是我们自己已经骗过了自己，认为作业“的确”是放在家里了，实际上，作业还在书包里没有动过。没骗过自己，谎言就不可能顺理成章从意识转换成言行。骗过了别人，就先欺骗了自己。

大抵上，我认为的欺骗就是建立在骗过自己的基础上，让别人的认知与事实有了些许偏差。我不愿骗过自己，所以，我也不愿撒谎。
