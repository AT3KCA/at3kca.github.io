对于轻度用户，这里局限在办公、轻度娱乐、开发上，Linux独特的命令行操作模式提供了一个统一管理所有应用的平台，不同发行版之间亦有差异的包管理器，使得管理应用变得极其简便，最常见的场景，安装一个应用，只需要在终端里学习发送一行指令。

sudo pacman -S firefox

常见使用场景

文本编辑

Linux终端环境中，VIM提供了较为顺手的文本编辑环境，它的控制基于键盘输入，需要一段时间学习，不过熟练后，都能感受到这是种不错的方案。

对于更高级的文本排版任务，LibreOffice Word也不失为一种选择。除此之外，我便没有尝试更多方案了，对于纯文本无排版的操作，VIM已经能胜任了。

互联网

互联网浏览的选择很多，有Firefox、Chrome、Edge等浏览器作为选择。可以说，有了浏览器，难题就解决大半了。

在Arch下，我选择Firefox作为日常浏览器，因为它直接就在官方仓库内，安装只需一行命令：

sudo pacman -S firefox

Firefox有着严格的隐私控制和看的过去的优化，如果反感个人信息被收集，Firefox是个很好的选择。它本身也提供了拓展接口，你可以很方便的自定义一切，就一句古话：

工具是思维的延伸。

顺手的工具肯定便于日常使用对吗？

它在Linux上已经有了完整的支持，在KDE桌面门户下，一切都是开箱即用的。

娱乐

玩家们试图在任何系统上打游戏，Linux上也不例外。2026年前后，关于如何在Linux系统上进行游戏，已经有了很多方案。

Windows原生游戏

Steam Proton便是脱颖而出的方案，对于大部分的游戏及其反作弊，Proton都有广泛的支持。Proton作为Wine的分支，理所应当的，它采用了Windows API转译的方案，属于一种兼容层，和直接搭建Windows虚拟机相比，它性能较高，硬件支持好。甚至说，它还能用于启动和游戏毫不相关的Windows原生应用。

当然，也不是所有应用都能在转译下跑起来，实在跑不起来，就考虑更换Linux原生方案或者放弃吧。

一切的一切

丰富的桌面环境、窗口管理器是Linux的一大特色，找到适合自己的才是最重要的。在这里，我推荐KDE Plasma，一个现代、低占用的桌面环境，基本模拟了Windows的操作习惯，可以方便地迁移过来。后期也可以加装更多拓展实现更惊人的视觉效果。

Hyprland是一个平铺窗口管理器，如果你喜欢快捷键操作、更多特效、高度自定义可以尝试。

日常

Firefox，Steam（Proton），SPlayer，QQ，WeChat。仅此而已，就能撑起一个轻度用户的日常使用，就Linux本身的低占用来看，甚至更适合这些工作呢。

学会终端操作是必要的，在UI内，总会碰到一些莫名奇妙的问题，有时候一个sudo或者rm就能产生奇效。
